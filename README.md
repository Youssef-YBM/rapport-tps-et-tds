# Travaux pratiques UML

## Présentation

Ce dossier regroupe les ressources de travail pour les travaux pratiques du module « UML avancé et ingénierie des processus ».

Étudiant : ERRAMI Youssef

## Contenu

- `Corrige_UML_ERRAMI_Youssef.pdf` : document PDF présent à la racine du dossier.
- `TP1-Calculator/` : projet Java Maven du TP1 sur le Test First Development (TFD). Le code, les tests JUnit et les instructions d'exécution se trouvent dans ce dossier.

## Plan des travaux pratiques

1. **TP1 — Test First Development** : développement et tests de la calculatrice Java.
2. **TP2 — Gestion de projet agile : Backlogs** : travaux réalisés avec Jira.
3. **TP3 — Gestion de projet agile : Roadmap** : travaux réalisés avec Jira.
4. **TP4 — Planning Poker et planification** : travaux réalisés avec Jira.

Les éléments Jira et leurs captures d'écran seront ajoutés aux sections correspondantes du compte rendu lorsqu'ils seront disponibles.

## Exécuter le TP1

Ouvrir PowerShell dans le dossier `TP1-Calculator`, puis suivre les instructions de [son README](./TP1-Calculator/README.md) pour configurer Java et Maven, compiler le projet et lancer les tests.
